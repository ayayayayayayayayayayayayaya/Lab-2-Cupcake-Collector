# Lab-2-Cupcake-Collector
This is a platformer game that was made for a Project from my A.I. Gaming and Programming class!

The whole game is programmed using Python and Pygame, and the game works by traversing the screen to collect as many lemons as possible. As you reach higher amounts of lemons collected, the map resets and new platforms replace the old ones and move to new positions.

Sprites
- A literal can of Sprite (Player)
- lemons (the "Cupcake")

Other Cool Stuff
- Platforms that change at every 30 point threshold
- two moving platforms that move horizontally across the screen at random speeds
- Score display
